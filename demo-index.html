📊 使用场景

场景1：通话前准备

打开客户详情页，查看完整的客户分析和话术建议，做好充分准备后再拨打电话

场景2：通话中实时指导

使用跟进编辑弹窗，边沟通边打标签，系统实时提供针对性话术支持

场景3：新人培训

展示不同标签组合的推荐变化，帮助新人快速掌握销售技巧和话术

🚀 技术说明

技术栈：React 18 + TypeScript + Ant Design 5

特点：纯前端实现，无需后端，可直接在浏览器中运行

兼容性：支持 Chrome、Firefox、Safari、Edge 等现代浏览器

💻 本地运行完整版：
1. 下载项目代码
2. 执行 npm install
3. 执行 npm run dev
4. 访问 http://localhost:3000
